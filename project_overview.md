# Project overview

PlantCare AI is a student demonstration of image classification for plant leaf photos. The user uploads an image; a CNN produces probabilities across the classes represented in the selected dataset. The app presents the highest-scoring class and general educational notes.

## Users
- Students learning computer vision and deep learning.
- Demonstration audiences evaluating a basic ML workflow.

## Inputs and outputs
- Input: JPG, JPEG, or PNG leaf photo.
- Output: predicted dataset class and model confidence.

## Safety and reliability
This is not a validated agricultural diagnostic service. Dataset domain shift, poor images, unseen diseases, and similar visual symptoms can lead to incorrect predictions.
